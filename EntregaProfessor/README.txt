INSTRUÇÕES DE INSTALAÇÃO
========================

1. Abrir MySQL Workbench
2. Conectar no servidor local
3. Abrir o arquivo banco\aluguel_veiculos.sql
4. Executar o script (Ctrl+Shift+Enter)
5. Abrir NetBeans
6. File → Open Project → selecionar pasta projeto\SistemaAluguelVeiculos
7. Botão direito no projeto → Clean and Build
8. Botão direito no projeto → Run
